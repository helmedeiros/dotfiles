# Topics that cannot SKIP on a bare machine, because installing is exactly
# what they are supposed to do there: they clone or download before they can
# tell whether there is any work to do, and the harness has no network.
#
# test/script/fresh_machine_test.bats runs two scenarios.
#
#   bare machine       every topic NOT listed here must exit 0. An installer
#                      that exits non-zero lands in script/install's "these
#                      installers failed" list, which should mean something
#                      broke — not that you do not use that tool.
#
#   already provisioned  every topic listed here must still exit 0 once the
#                      thing it installs is present. That is the re-run that
#                      happens on every bin/dot, and it is where sdkman was
#                      re-downloading a candidate it already had while
#                      reporting a successful install as a failure.
#
# So nothing here is untested — these topics are held to the second contract
# instead of the first. Adding a topic means writing its fixture in
# provision_topic; the list may only SHRINK.
hoster
kcc
sdkman
tools
vault
vimac
zsh-completion-generator
